# TK CABINET 1.99.468

[Tải bộ cài TK CABINET 1.99.468 đã ký và mã hóa](https://github.com/kimtrongcnc-ops/tk-cabinet-updates/releases/download/v1.99.468/TK_CABINET_1.99.468_MA_HOA.rbz)

Máy đang dùng TK CABINET mở **Cài đặt chung → Kiểm tra bản cập nhật**. Sau khi cài, lưu bản vẽ rồi đóng và mở lại SketchUp.

Trên máy mới, mở **Extension Manager → Install Extension** và chọn bộ cài ở trên.

Bản này gộp các thay đổi từ 1.99.445 đến 1.99.468 về xếp tấm, layer, đường dao, mô phỏng và nhập Corel. Khi xuất NC, TK lưu bảng Excel vật tư cùng bộ file của đơn hàng.
